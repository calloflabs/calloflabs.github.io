# 📄 초록 제출하러 가는 길 (Road to Submission)

학회 초록 마감 90초 전. 초록 한 장은 손에 들렸고 제출 창구는 차도 50개 너머에 있다. 못 내면 죽는다. 비유가 아니다.

▶️ 플레이: https://road-to-submission.vercel.app · English: https://road-to-submission.vercel.app/?lang=en

**연구실에서 살아남기 외전**

## 조작

- 탭하면 한 차선 앞으로 · 좌우 스와이프는 옆으로 · 아래 스와이프는 뒤로.
- 두 손가락 드래그로 시점을 돌리고 핀치로 거리를 바꿉니다.
- 기차 건널목은 경고등이 켜지면 들어가지 마세요.

## 랭킹

제출 성공 1000 + 남은 초×25 + 아슬아슬×60. 실패하면 건넌 차선×12 + 아슬아슬×60.

현재 버전: v1.0.0
