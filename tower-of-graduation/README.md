# 🏯 졸업의 탑 (Tower of Graduation)

탑 꼭대기에 졸업장이 있다. 리뷰어 떼와 교수님보다 빨리 올라가라.

▶️ 플레이: https://tower-of-graduation.vercel.app · English: https://tower-of-graduation.vercel.app/?lang=en

**연구실에서 살아남기 외전**

## 조작

- 좌우로 드래그하면 옆으로 움직이며 떠 있는 데이터를 줍습니다.
- 위로 스와이프(또는 탭)는 점프 · 아래로 스와이프는 슬라이드.
- 모퉁이에서는 화살표 방향으로 빠르게 튕겨야 회전합니다. 못 돌면 벽입니다.
- 교수님·리뷰어·거대 망치는 체력 1칸 · 책더미·현수막은 데이터 · 끊긴 길은 즉시 탈락.

## 랭킹

점수 = 데이터 + 논문×100. 100층에서 졸업하지만 탑은 끝나지 않습니다.
